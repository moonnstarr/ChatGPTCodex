# NexaSocial Studio

A modern front-end concept for an enterprise-grade social media content generator.

## Features

- Niche and audience inputs for campaign generation.
- Multi-agent panel for writer discovery, content composition, and viral visual planning.
- Platform-specific output tabs for LinkedIn, Instagram, Facebook, and X.
- Visual style inspired by premium SaaS products with glassmorphism and gradient lighting.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
